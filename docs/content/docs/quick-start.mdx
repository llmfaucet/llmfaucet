## OpenAI-compatible request

```bash
curl https://<worker-subdomain>.workers.dev/v1/chat/completions \
  -H 'content-type: application/json' \
  -H 'authorization: Bearer free' \
  -d '{"model":"auto","messages":[{"role":"user","content":"Say hello"}]}'
```

The service applies anonymous daily budgets and routes requests to healthy upstreams.

## Coding agents

- OpenAI-compatible clients: base URL `https://<worker-subdomain>.workers.dev/v1`, key `free`, model `auto`.
- Aider: `--openai-api-base https://<worker-subdomain>.workers.dev/v1 --openai-api-key free --model openai/auto`.
- Claude Code: use the Anthropic-compatible endpoint at `/v1/messages`.

Free upstream limits change without notice; this service has no SLA.
