# llmfaucet

One OpenAI-compatible endpoint for documented, anonymous free AI providers.

## Start here

Use the temporary `workers.dev` URL printed by Wrangler after deployment:

```bash
curl https://<worker-subdomain>.workers.dev/v1/models
```

See [Quick start](/docs/quick-start) for agent configuration and request examples.
