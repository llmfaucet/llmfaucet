---
title: GitHub Sponsors
description: Optional identity and fair-use entitlements.
---

GitHub Sponsors is a separate identity and entitlement layer. It does not buy
model access or guarantee tokens, latency, a provider, or uptime.

Anonymous access remains 20 requests/day. A registered key is 50 requests/day.
Active monthly Sponsor tiers receive higher request limits and queue priority
when the GitHub sponsorship target is `llmfaucet`. GitHub handles payment;
llmfaucet stores only identity, entitlement, and one-way API-key hashes.

OAuth, webhook, and production entitlement activation require configured GitHub
OAuth applications, webhook secrets, a verified sponsorship target, and a
deployed HTTPS callback. Until those credentials exist, no sponsor entitlement
is granted by configuration alone.
