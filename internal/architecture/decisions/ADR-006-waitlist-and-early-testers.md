# ADR-006: Waitlist and early testers

Status: Accepted

## Context

Preview capacity should be introduced in small, reviewable groups.

## Decision

Store one authenticated application per GitHub account, keep reviewer notes
private, and issue time-limited preview entitlement/key access only after an
admin approval.

## Consequences

Tester diversity and reproducible feedback can be reviewed without pretending
selection is guaranteed or sponsorship is required.

## Alternatives considered

Open anonymous invitations and artificial spot counters were rejected.
