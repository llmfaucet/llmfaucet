# Code of Conduct

## Our standard

We want llmfaucet to be welcoming, respectful, and useful to everyone.
Participants must communicate constructively and avoid harassment, personal
attacks, discrimination, doxxing, sexualized language, and disruptive behavior.

## Enforcement

Project maintainers may remove comments, close issues, or restrict participation
when behavior violates this standard. Report conduct concerns privately to the
maintainers through the security contact listed in `SECURITY.md`.

Retaliation against anyone who reports a concern in good faith is not accepted.

## Scope

This code applies in project spaces, issue trackers, pull requests, chats, and
events where someone is representing the project.
